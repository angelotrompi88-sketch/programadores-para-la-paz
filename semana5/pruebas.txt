- http://localhost:3000 -> El servidor responde con el texto "Servidor activo". Es la ruta principal o raíz del proyecto.
- http://localhost:3000/saludo -> El servidor responde con el texto "Hola comunidad". Se utiliza para mostrar un mensaje estático a los usuarios.
- http://localhost:3000/mensaje/juan -> El servidor lee el parámetro dinámico ":nombre" de la URL (en este caso 'juan') y responde de forma personalizada diciendo "Hola juan".
